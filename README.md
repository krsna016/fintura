# Transaction Intelligence Platform (TIP)

Transaction Intelligence Platform (TIP) is a commercial SaaS application to ingest, parse, clean, and export multi-bank statements into accounting-ready formats.

## Architecture & Tech Stack
- **Frontend:** Next.js 15, TypeScript, Tailwind CSS, shadcn/ui
- **Backend:** Supabase (Auth, DB PostgreSQL, Storage)
- **Parser Service:** Python (Pandas, OpenPyXL, pdfplumber, Regex)
