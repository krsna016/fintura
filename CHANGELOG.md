# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-06-18

### Added
- Created root `Makefile` orchestrating testing and linting across Next.js and FastAPI folders.
- Integrated `pre-commit` hook pipelines validating formatting and syntax conventions.
- Added GitHub templates: bug report templates, feature requests, pull requests, and dependabot configurations.
- Implemented static analysis workflows and CodeQL security gates.
- Added enterprise Apache-2.0 licensing and security response frameworks.

### Changed
- Standardized root project configuration and folder layouts.
- Refactored vercel configuration parameters for seamless hosting compatibility.
