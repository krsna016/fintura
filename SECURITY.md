# Security Policy

## Supported Versions

We actively monitor and support security patches for the following versions:

| Version | Supported |
| ------- | --------- |
| Main    | ✅ Yes    |
| < 1.0.0 | ❌ No     |

## Reporting a Vulnerability

We take the security of this project seriously. If you find a security issue or credential exposure:

1. **Do not** open a public GitHub Issue.
2. Email a detailed report to `contact.anuragpareek@gmail.com`.
3. Include clear steps to reproduce the vulnerability, including sample code if applicable.

We will acknowledge receipt of your report within 48 hours and work with you to patch the issue before making a public advisory.
